# 305 nippou-app デザインガイド

> 主上（めめんが）指示 2026-08-25 13:24: 「ダッシュボードも営業実績のように画面幅をしっかり使ってください。**これは、本案件のデザインガイドとなります**」

## 1. 画面幅を最大限に使う（全幅レイアウト原則）

主要な一覧・ダッシュボード・分析系の画面は、**`max-w-*xl mx-auto` のような中央寄せ幅制限を付けず、`w-full` で画面幅いっぱいを使う**こと。基準は「営業実績ダッシュボード」(`src/features/salesPerf/SalesPerfPage.tsx`)のレイアウト＝サイドバー右端から右端まで全幅利用。

### 適用対象（全幅が原則）
- ダッシュボード / 営業実績（`SalesDashboardPage` / `TeamDashboardPage` / `SalesPerfPage`）
- 商談一覧 / 顧客一覧（世帯・契約） / その他データ一覧・テーブル・カード群
- 案件詳細など、情報量の多い画面

### 例外（中央寄せ幅制限を許容してよい）
- ログイン等の単票フォーム、モーダル内の狭い入力など、幅を絞った方が読みやすいもの。
- ただし「データを一覧・分析する画面」は原則全幅。

### 実装メモ
- ❌ `className="max-w-4xl mx-auto px-4 py-4"`
- ✅ `className="w-full px-4 py-4"`
- グリッドは全幅を活かせるよう、画面幅に応じて列数を増やす（例: `grid-cols-1 lg:grid-cols-2 xl:grid-cols-3`）ことを検討する。空白の間延びを避ける。

## 2. その他（既存の運用ルールを踏襲）
- AIスロップを避け、既存の tailwind トーン（バッジ・アコーディオン・カード）に合わせる。
- 空白・未実装セクションを残さない。デモはデータが入って見える状態にする（(0) の空タブを作らない）。
